How this works: when you manually confirm a Pro Monthly payment via Telegram, go to Firebase Console → Firestore Database → users collection → the user's document, and set planExpiresAt to a Timestamp 30 days from today (alongside plan: "pro"). This page reads that field and flags anyone overdue or due within 7 days. Lifetime users don't need this field — they never expire.
